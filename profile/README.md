## 🧠 Overview

**BoxCutter** is a Blender add-on created to make hard-surface modeling faster through an interactive boolean-based workflow. It allows artists to draw and manipulate cutter shapes directly in the viewport to produce holes, panels, slots, recesses, slices, and other structural details.

The add-on focuses on an efficient modeling process where cutters can be positioned, resized, rotated, and refined while the model remains visible. This makes it easier to experiment with different design ideas without repeatedly constructing boolean setups manually.

BoxCutter supports a variety of cutter shapes and modeling approaches, making it suitable for mechanical assets, vehicles, props, architectural forms, product concepts, and futuristic designs. Beveling, symmetry, and other controls can be incorporated into the cutting workflow for more refined results.

Because the workflow integrates directly with Blender's modeling tools and modifiers, artists can continue editing the resulting geometry after each operation. **BoxCutter** provides a practical environment for developing detailed hard-surface models while keeping the process fast and visually driven.

## Additional Information for Windows Users

**BoxCutter** adds an interactive boolean modeling workflow to Blender, allowing users to create detailed hard-surface forms directly in the viewport. Cutter objects can be positioned and modified while designing the model.

The add-on is well suited to mechanical objects, vehicles, props, architectural elements, and other structured assets. Its cutting, bevel, symmetry, and modifier workflows provide additional control over the final geometry.

The non-destructive approach makes it possible to revisit cutters and adjust design elements as a project develops. This is useful when proportions, panel layouts, or other details need to be changed.

**BoxCutter** keeps hard-surface cutting inside Blender and helps make detailed modeling more efficient and visually intuitive.
